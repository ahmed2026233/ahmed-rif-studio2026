# AHMED RIF STUDIO Portfolio — v1.2.2

A bilingual Arabic/English portfolio for AHMED RIF STUDIO, built with semantic HTML, responsive CSS and vanilla JavaScript. The portfolio presents four distinct concept projects with substantive case studies and interactive demo flows.

## Included projects
- **Maison Atlas** — luxury hospitality / hotel booking experience
- **Monarch Kitchen** — restaurant menu / reservation experience
- **Nova Clinic** — healthcare / appointment conversion experience
- **Northline Properties** — real estate discovery / enquiry experience

## Core portfolio positioning
AHMED RIF STUDIO presents websites as business tools, not templates. The portfolio structure communicates the challenge, solution, key features and business value behind each concept.

## Production-readiness additions
- Web App Manifest and consistent theme metadata.
- `robots.txt` for static deployment.
- Branded SVG favicon across the portfolio and project pages.
- Custom `404.html` fallback for static hosts.
- Open Graph site metadata and page-level descriptions.
- Dark color-scheme hints for browser UI consistency.

## Production polish
- Google Fonts are loaded from document-level stylesheets instead of CSS `@import`, allowing the browser to discover the font resource earlier.
- Project pages now include font preconnects and consistent dark color-scheme metadata.
- Removed a duplicate theme-color declaration from the Northline Properties page.
- Added an alternate Open Graph locale for the bilingual homepage.

## Run
Open `index.html` locally, or deploy the folder to a static host such as Vercel, Netlify or GitHub Pages.
